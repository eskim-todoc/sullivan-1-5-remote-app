## 2. 구현 결과

### 2.1 «4.5 로 판단되는 시점» 의 자동 읽기 — 승인 조건

`advanceProbe()` 의 판별 종료 자리에 넣었다(`MainActivity.java:1606`).

```
PROBE_STEP_VERSION (버전 확정) → PROBE_STEP_LINK_ALL → PROBE_STEP_GATING → NONE
                                                                            └ requestMaxTxPowerRead("세대 판별 완료")
```

이 자리를 고른 근거 둘.

- **버전이 이미 확정**되어 있다 — `PROBE_STEP_VERSION` 에서 `handleRcVersionResponse()` 가 minor 를 넣는다
- **판별 상태 기계가 끝나** 다음 요청과 겹치지 않는다

값이 오면 `applyLinkParam()` → `setValueMaxTxPowerLevel()` → LiveData → `updateMaxPowerText()` 로 **상태 표시에 자동으로 뜬다**(`RemoteControlFragment.java:2655`).

**화면 갱신은 두 경로가 받친다** — 값이 올 때(LiveData)와 세대가 확정될 때(`applyFwRelease()` → `updateMaxPowerText()`, `:3125`). 뒤쪽이 있어 4.5 미만에서 버튼·표시가 숨겨지는 것도 버전 확정 즉시 반영된다.

## 3. 하위 호환 전수 확인

**인덱스 16 이 나가는 경로는 둘뿐이고 둘 다 게이트 뒤에 있다.**

| 경로 | 게이트 |
|---|---|
| 읽기 `sendLinkParamRead(16)` (`:1205`) | 같은 함수 진입부 `if (!isMaxTxPowerSupported()) return;` (`:1196`) |
| 쓰기 `sendLinkParam(16, level)` (`:2456`) | 같은 함수 진입부 가드 + 버튼이 4.5 미만에서 `INVISIBLE` |

| 퇴행 후보 | 결과 |
|---|---|
| `RC_LINK_IDX_MAX` 16 이 전체 읽기 파서에 영향 | **없음** — 파서를 `RC_LINK_IDX_ALL_READ_MAX`(15)로 바꿨다 |
| 게이트 `default` 가 16 을 «지원» 판정 | **없음** — `case 16` 을 앞에 뒀다 |
| 하한 다이얼로그가 좁아짐 | **4.5 에서만** — 상한이 `UNKNOWN` 이거나 4.5 미만이면 기존 213 |
| 하한 목록이 좁아져 체크 인덱스가 범위 밖 | **막았다** — `Math.max(0, Math.min(count-1, ...))` (계획 검증 §2.3 위험 B) |
| 에러 문구 변화 | **상한 쓰기 대기 중일 때만** — 그 밖은 기존 문구 |
| 상태 표시 격자 어긋남 | **없음** — 1행이 5열이 되면서 나머지 4행에 자리 맞춤을 넣어 5열로 통일 |

## 4. 빌드

```
./gradlew :app:assembleDebug   →  BUILD SUCCESSFUL
app/build/outputs/apk/debug/app-debug.apk  (16,217,971 bytes)
```

> **빌드 중 사고 1건.** 다이얼로그 메시지의 `\n` 이 셸 heredoc 을 지나며 **실제 줄바꿈**이 되어
> Java 문자열이 깨졌다(`unclosed string literal`). **이 저장소에서 세 번째** 같은 사고다.
> `System.lineSeparator()` 로 바꿔 해결했다. **문자열 리터럴이 든 Java 코드는 셸을 거치지 않는
> 편집 도구로 넣어야 한다.**

## 5. 실기 확인 대기 항목

실기 불가 상태다. 4.4 작업과 같이 대기로 둔다.

1. 4.5 기기 연결 시 **판별 완료 직후 상한이 자동으로 읽히고 상태 표시에 뜨는가**
2. 하한선 미만을 쓰면 에러 타입 2 가 오고 앱 문구가 «범위 밖 + 지금 범위» 로 갈리는가
3. 상한을 낮춘 뒤 `Cur` 이 즉시 안 내려가는가 (정상)
4. 4.3·4.4 기기에서 `Max PMIC` 가 숨겨지고 기존 동작이 그대로인가
5. 리셋 직후 첫 연결에서 214 가 쓰이는가 (`TDC_LINK_MAX_POWER_SAFE_BOOT`)
6. 하한 다이얼로그가 상한−1 에서 끊기는가
