# 요구사항

**TL;DR**: 펌웨어 `0x59` 가 4.4 로 올라가면서 재시도 코인이 켜고 끄는 스위치에서 개수가 됐다. 앱이 4.3 과 4.4 를 **둘 다** 다뤄야 하고, 4.4 에서는 개수를 고르고 견디는 시간을 알려 주며 백텔 모드에서 무한만 유효하다는 새 규칙도 따라야 한다.

## 1. 배경

은수님 지시 (2026-08-26): *"펌웨어에서 0x59 패킷의 버전이 4.4로 올라갔어. 4.3, 4.4 버전에 따라 다 사용할 수 있게 해줘. 4.4에서는 현재 Coin의 개수 설정이 가장 큰 변경사항이야."*

펌웨어 문서가 정본이다 — [`0x59 버전 이력`](../../../../sullivan-1-5-fw-hw-test-link-pwr-bt-period/docs/참고/리모콘%20프로토콜/0x59%20버전%20이력.md) §3 · [`0x59 프로토콜 규격`](../../../../sullivan-1-5-fw-hw-test-link-pwr-bt-period/docs/참고/리모콘%20프로토콜/0x59%20프로토콜%20규격.md) §4 · [`설정 의존성과 앱 UI 규칙`](../../../../sullivan-1-5-fw-hw-test-link-pwr-bt-period/docs/참고/리모콘%20프로토콜/설정%20의존성과%20앱%20UI%20규칙.md) §3·§6.

## 2. 4.4 가 바꾼 것

| 구분 | 4.3 까지 | 4.4 |
|---|---|---|
| 인덱스 7 범위 | `0` / `1` | **`0` · `1~100` · `255`** (`101~254` 거부) |
| 인덱스 7 뜻 | 켜고 끄기 | `0` 비활성 · `1~100` **개수** · `255` 무한 |
| 영속 | 파일 | `0~100` 파일 · **`255` 만 휘발** |
| 인덱스 8 | 무한 켜기 | 살아 있음. **인덱스 7 의 `255` 와 같은 내부 플래그** |
| 무한 설정 | 인덱스 8 에 `1` | **인덱스 7 에 `255` 하나로 끝** |
| 백텔 모드에서 | 코인 전체가 무시 | **개수만 무시. `255` 는 유효** |
| 코인 재시도 Tx 상향 | 2 스텝 고정 | **인덱스 5(상승 스텝)를 따름** |
| 개수를 `0` 으로 | 남은 코인 1개가 첫 실패를 봐줌 | **즉시 반영** |

인덱스 개수(15)와 전체 읽기 크기(20바이트)는 **그대로**다.

## 3. 요구사항

### 요구사항_1 — 4.3 과 4.4 를 함께 다룬다

연결된 사운드처리기의 minor 로 갈라, 4.4 이상이면 개수 방식, 4.3 이하면 지금의 켜고 끄기 방식을 쓴다. **어느 쪽에 붙어도 코인을 읽고 설정할 수 있어야 한다.**

### 요구사항_2 — 개수를 고른다

4.4 에서는 **무한 · 비활성 · 1 · 2 · … · 100** 순으로 고른다(규격서가 지정한 순서).

### 요구사항_3 — 견디는 시간을 알려 준다

규격서: *"개수를 시간으로 환산하려면 인덱스 2(백텔 주기)를 곱한다. … 사실상 무한에 가깝다는 것을 앱이 알려 주는 편이 좋다."*

개수마다 **`개수 × 백텔주기 × 100ms`** 를 함께 보여 준다.

### 요구사항_4 — 무한은 저장되지 않는다고 알린다

`255` 만 휘발이다. 전원을 껐다 켜면 파일에 남은 직전 개수로 돌아간다.

### 요구사항_5 — 백텔 수신 기준 모드의 새 규칙

지금 앱은 이 모드에서 **코인 버튼을 통째로 잠근다.** 4.4 에서는 **개수만 무시되고 `255`(무한)는 유효**하므로 버튼을 열어 두어야 한다. 대신 개수가 쓰이지 않는다는 것은 알린다.

### 요구사항_6 — 상승 스텝 동반 효과를 경고한다

코인 재시도 시 Tx 파워 상향이 인덱스 5 를 따른다. 스텝 40 이면 재시도 한 번에 **1.0V** 다. 문서가 *"무력화가 아니라 동반 효과라 앱이 경고만 하면 된다"* 고 정했다.

### 요구사항_7 — 무한 판정은 두 인덱스를 함께 본다

인덱스 7 의 `255` 와 인덱스 8 의 `1` 이 같은 상태다. **어느 쪽으로 켜져 있어도 «무한» 으로 읽어야** 한다.

### 요구사항_8 — 화면 표시

상태 격자의 `Coin` 칸이 4.4 에서 **개수를 보여** 준다. 무한이면 `∞`, 비활성이면 `Off`, 개수면 그 수.

## 4. 제약

| 제약 | 내용 |
|---|---|
| 실기 확인 | 4.4 펌웨어가 올라간 사운드처리기에 붙여 봐야 최종 확인이 된다 |
| 문서 불일치 | 의존성 문서 §6.1 의 **의사코드**가 아직 코인을 통째로 잠그도록 쓰여 있다. 같은 절의 **표와 §3 매트릭스**는 «개수만» 이라고 한다. 분석에서 판정한다 |
