# 계획 검증

**TL;DR**: 계획을 요구사항 8건과 일대일로 대조해 빠진 것이 없음을 확인했다. 의존 순서도 맞고 4.3 회귀 확인 항목이 다섯 개 붙어 있다. 구현에서 지킬 보완 지시 3건을 계획이 모두 흡수했다.

## 구현 지시

### 지시_1 — 다이얼로그 배열은 한 반복으로 함께 채운다

표시 문자열과 보낼 값을 **따로 만들지 않는다.** 하나가 어긋나면 엉뚱한 값이 나가는데 화면으로는 알 수 없다.

### 지시_2 — 백텔 주기를 모르면 시간을 붙이지 않는다

`LINK_VALUE_UNKNOWN` 이면 개수만 보여 준다. 모르는 값으로 계산한 숫자를 보여 주는 것이 가장 나쁘다.

### 지시_3 — 4.3 경로를 지우지 않는다

`sendCoinMode` · `sendPendingOneCoinPacket` · `getCurrentCoinModeIndex` · 3택 다이얼로그는 **그대로 남긴다.**
