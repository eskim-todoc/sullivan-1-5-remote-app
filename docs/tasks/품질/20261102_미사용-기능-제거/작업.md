## 요청과 범위
사용자가 삭제 가능한 항목부터 실제 정리하고, Lock Screen/매뉴얼도 제거하며, SOUND1 GAIA 확장 기반과 기존 기능을 보존하면서 단계별 커밋을 요청했다. develop_ota_landscape_multi 유지, push/merge 없음. 실제 등록 DB/앱 데이터/서명 설정/배포 대상과 기존 미추적 자료는 변경하지 않는다. 복구 기준은 697eed5와 각 단계 커밋이다.

## 유지할 계약
- 제품 식별(SND1/SLVN), 세션/큐/타이머/인증/FF/OTA/로그/관리 기능 유지.
- 최초 등록·내부기 키 오류 복구에 쓰이는 AddUser/AddDevice/EditUser/UserGroupForm 유지.
- 현재 app_sans 서체와 단위 기호/제품 이미지 유지. 폰트 생성 원본은 런타임 미사용 판정만으로 지우지 않음.
- 데이터 형식/Room 마이그레이션/기존 키 보존. 실제 장치 설정을 쓰는 파괴 시험은 이번 정리의 기본 검증이 아님.

## 단계
1. 독립 미사용 연결 창/모델·애니메이션 제거.
2. 매뉴얼·잠금의 Activity/XML/설정 배선과 자산 제거.
3. 참조가 없는 리소스·이전 폰트 정리, 도구 입력 보존.
4. JVM·Android·SQLite·lint/빌드 및 가능한 실제 화면 확인 후 기록.


## 단계별 결과
| 단계 | 커밋 | 결과와 검증 |
|---|---|---|
| 기준 | 697eed5 | 기존 JVM 145개 / Android 16개. 린트 오류 0 |
| 1. 독립 미사용 코드 | 957415a | 연결 선택 창·모델·전용 시험과 미사용 애니메이션 6파일 제거. JVM 138개 / 린트 오류 0 / debug 빌드 통과 |
| 2. 잠금·매뉴얼 | 4511624 | 매뉴얼 전용 29파일과 LockScreen, 잠금 자산·설정 XML·Activity/상태 배선 제거. JVM 138개 / Android 17개 / 린트 오류 0 / debug 빌드 통과 |
| 3. 리소스·폰트 | f76c2d8 | 미사용 파일 68개 삭제, IBM 원본 3개 tools로 이동. 미사용 색 40개·dimen 17이름/51정의·style 4개 정리. 빌드/린트 통과, Android 17개 통과 |

- JVM 시험 수가 145→138로 줄어든 이유는 삭제한 ConnectionSelectorState 전용 시험 7개를 함께 제거했기 때문이다. 나머지 시험은 유지했다.
- Android 시험은 잠금 오버레이와 매뉴얼 진입점이 없는지 검사하는 1개를 추가해 16→17개다. 첫 실행은 루트 자식 수를 1로 잘못 기대해 실패했다. 필수 BLE 페어링 안내가 별도 자식임을 반영해 콘텐츠+페어링 안내 2개와 안내 초기 GONE, 제거 ID 부재를 검사하도록 수정했고 재실행 17개가 모두 통과했다.
- 잠금 초기화 버튼이 등록 DB를 삭제하던 경로도 함께 제거했다. 실제 등록 DB나 환경설정 파일을 삭제한 것은 아니다.
- 최초 등록·내부기 키 오류 복구·OS 페어링·장치 인증·NOP 수동 모드는 유지했다.
- 독립 검토 audit_transport가 최초 등록과 키 오류 복구, GATT, 기동/명시적 ＋ 검색, 화면 ID 정수값 보존을 확인했다. 핵심 프로토콜/세션/DB/FF 소스 40개는 697eed5와 동일하다(preservation-check.json).
- SQLite 마이그레이션·트랜잭션 시험 7개 통과. 실제 앱 데이터 대신 시험 DB를 사용했다.

## 최종 검증
- JVM 138개 실패 0, SQLite 7개 실패 0. 단계3은 리소스 변경이므로 JVM 작업은 UP-TO-DATE이며 단계2 결과를 유지한다.
- Android 17개 통과. 삭제한 사용자 폼 wrapper 대신 실제 사용되는 fragment_user_group을 렌더 시험에 넣어 등록 폼 검사를 유지했다.
- lint 오류 0, 경고 288. 단계2 경고 409에서 감소했다. debug 앱/시험 APK 빌드 성공.
- app_sans 4파일의 SHA-256 유지. 새 도구 경로에서 3두께 재생성 성공, 주요 glyph/layout/name 테이블 동일. 최종 phone/큰 글꼴/tablet의 현행 캡처 15개 해시도 정리 전과 동일했다.
- 휴대전화에 기존 앱을 덮어 설치했다. 시작 시 잠금 없음, ＋ 누르기 전 자동 검색 없음. ＋로 TODOC_OTE L FFFF(R4.5, MAC 끝65:4A) 연결 후 배터리80%·전압3.987V·전류−0.4mA·전력−1.5mW·Current PMIC4.325V 수신.
- 등록 사용자 4명·외부기 2대 유지. OTA 슬롯 조회 응답은 현재FF / 이전2였다. 마지막은 연결된 기본 제어 화면으로 복귀했다.
- 실제 4파일 OTA 전송, 맵 초기화, 제조번호/키 쓰기와 자극 설정 변경은 이번 삭제 검증에서 실행하지 않았다.
- 원본 res/font 46,054,098→2,771,431Bytes. IBM 9,499,828Bytes는 삭제 대신 tools/fonts/sources로 이동했다. 실제 debug APK는47,797,567→47,791,345Bytes로6,222Bytes 감소했다. 소스 정리 크기와 APK 감소를 혼동하지 않는다.
- 이전 시안의 IBM 직접 경로 5개도 새 도구 경로로 교정했다. 이 시안 디렉터리는 작업 시작 전부터 미추적이므로 전체를 새로 커밋하지 않았다.

## 보존 및 후속 경계
SOUND1 제품 식별·GATT/인증·세션·큐·타이머·로그·OTA 기반을 유지했다. 현재 앱에 실제 GAIA 통신을 구현했다는 뜻은 아니다. AddUser/AddDevice/EditUser/UserGroupForm은 최초 등록·키 오류 복구에 필요하다. UserFragment/DeviceFragment/EditDeviceFragment는 남은 factory/back 경로 통합과 시험 이후 별도 정리한다. 이번 작업에서 실제 DB, 앱 데이터, 서명 설정과 배포 대상 설정은 바꾸지 않았다.
