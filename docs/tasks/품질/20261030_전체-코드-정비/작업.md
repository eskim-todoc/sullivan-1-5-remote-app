## 범위와 보존 조건
사용자 요청: 앱 전체 최적화·버그 수정·BSD 스타일 적용을 단계적으로 커밋/검증하며 현재 기능 보존. 현재 develop_ota_landscape_multi를 유지하고 push/merge 없음. DB 삭제/앱 제거 없음. 서명 설정 및 배포 대상 로컬 수정 제외.

## 검토 분담
- audit_transport: MainActivity/connection/ota/params/ff 읽기 전용 점검.
- audit_registry: DB/마이그레이션/설정/로그/빌드 읽기 전용 점검.
- preview_review: fragment/ui/list/view_model 수명과 렌더링 읽기 전용 점검.
- 루트: 기준 커밋, 통합, 코드 스타일, 린트와 전체 시험/실기.

## 검증 기준
현재 제어/글래스/B폰트/한번에 한장치 검색/등록/FF/OTA/맵 기능 보존. 각 수정은 회귀 검사 또는 동일 동작 근거를 둔다. 테스트 성공과 미실행 실기는 구분한다. 기존 전체OTA/내부기물리분리 미실행 범위를 성공으로 옮기지 않는다.
